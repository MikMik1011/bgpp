# BGPP
## Fair Usage Policy

This service is officially hosted at https://bgpp.misa.st and functions only as a proxy layer to the official API, which has been reverse engineered for compatibility and research.

### 1. Permitted Use
The BGPP proxy API may be used only in:
- The official BGPP application.
- Personal research, testing, or educational work.

### 2. Third Party Projects
If you want to use this API for your own project, you must either:
- Adapt the source code to your own needs, or
- Self host your own instance of this project.

Direct use of the production API at bgpp.misa.st in external applications, tools, or automated systems is not allowed.

### 3. Restrictions
Usage that places excessive load, bypasses limits, scrapes or mirrors data, undermines service stability, or violates intended use is prohibited.

### 4. Enforcement
Any activity that violates this policy may result in temporary or permanent blocking of requests without prior notice.

### 5. Changes
This policy may be updated at any time. Continued use of the proxy API indicates acceptance of the latest version.
